# 平台同步回执存放约定

用户明确授权平台同步且需要保留独立回执时，默认写入工程根目录 `platform-sync/`，名称采用 `<requirement-id>-<YYYYMMDD>[-<sequence>].<ext>`；同一需求同日多份记录不得覆盖。记录来源版本、源文件 SHA、平台返回标识、同步状态及实际记录时间；不能虚构成功回执。

历史回执如已保存于其他归档目录，保留原路径、内容、SHA-256 及引用；新记录才按本约定存放，不为整理位置迁移或重写历史 Manifest。

本目录的独立平台回执不替代需求正式 Manifest。如确需登记为正式 artifact，按现有 Manifest 版本、role、source_version 和 SHA-256 流程发布。回执记录本身不构成平台写入授权。

真实平台回执属于用户本地/组织证据，不进入公开 Git 仓库；本 README 仅提供通用规范。
